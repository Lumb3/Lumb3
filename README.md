## Making 1,000+ PDFs easier to review

At Unitel Group, a five-person team had more than 1,000 PDFs to review by hand. I built a Java and Quarkus microservice service that extracts text with Tess4J OCR and uses Gemini to turn it into structured JSON. Reviewers can now directly start with the extracted information. 

## Building a campus hub for Adobe Student Ambassadors

I’m building a React and TypeScript web app where University of Utah students can find Adobe events, read program updates, and apply to join.
