## Making 1,000+ PDFs easier to review

At Unitel Group, a five-person team had more than 1,000 PDFs to review manually. I built a Java and Quarkus microservice that extracts text using Tess4J OCR and uses Gemini to convert it into structured JSON. Instead of starting from scratch, reviewers can now work directly with the extracted information.
